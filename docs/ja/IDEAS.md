# 発展のためのアイデア

> [🇬🇧 English](../en/IDEAS.md) · [🇸🇪 Svenska](../sv/IDEAS.md) · 🇯🇵 日本語

ゲーム、クライアント、そしてコースそのもののためのアイデア集です。多くはチャレンジ、
自分のプロジェクト、将来のレッスンとして使えます。

## ゲーム

**Dwarf Fortress と Caves of Qud に影響を受けて**

- **歴史の生成:** ゲーム開始前に村の歴史を生成する。創設者、戦争、失われた遺物……
  そして NPC に語らせる。生成された歴史が書かれた本を世界に置く。
- **HP の代わりに体の部位:** 腕に当たると剣を落とす。
- **変異と派閥**（Qud）: 集団ごとの評判によって、生き物の反応が変わる。
- **素材と温度:** 木は燃え、水は冬に凍り、溶岩は石を溶かす。ゲームループで動く
  シミュレーションの仕組み。
- **生態系:** オオカミはシカを狩り、シカは草を食べる。シカを狩り尽くすと、
  オオカミが飢えて……

**古典的な MUD**

- 昼夜と天気: 夜はマップが暗くなり、雨は音を立てて視界を悪くする。
- Lua で書くクエスト（フェーズ 5）。プレイヤーごとの状態付き。
- 製作: データファイルにレシピ。マドビーの鍛冶屋が役に立つようになる。
- 経済: 店、需要と供給で変わる価格。
- フェーズ 4 の経路探索を使うペットや仲間。
- 再起動しても残る手紙と掲示板。
- チャンネル（`ooc`、`newbie`）と無視リスト。
- パーティ: 経験値を分け合い、マップでお互いが見える。

**技術的なゲーム機能**

- **リプレイ:** プロトコルが JSON の行なので、クライアントはセッションをファイルに
  記録して再生できる。サーバーはまったく不要。
- **観戦モード:** 他のプレイヤーを追いかけ、その人が見ているものを見る。
- **もっと賢いボット:** 負荷テスト（レッスン 44）のボットはさまようだけです。目標を
  持たせれば（全部屋の探検、戦闘、取引）、限界だけでなくバグも見つけてくれます。
- **実績とランキング。**

**外の世界で**

- **本物の telnet:** IAC ネゴシエーション、NAWS（ウィンドウサイズ）、**GMCP**。Mudlet の
  ような一般的な MUD クライアントでも、マップとステータスバーを表示できるように。
- **サーバー側の Rust:** 視界やゾーンの生成器を Rust のライブラリとして書く（wazero で
  動かす WASM モジュール（レッスン 33）か cgo で）。速さと開発体験を比べる。
- **非同期の端末クライアント:** スレッドとチャネルの代わりに `tokio`（レッスン 44）で
  端末クライアントを書き直す。
- **複数のサーバー、1 つの世界:** 世界を複数のプロセスに分け、プレイヤーが行き来できるように。

## クライアント

- 近くのマップの横に、探検済みの世界全体のミニマップ。
- テーマ: 選べるカラーパレット。**色覚多様性に配慮した** もの（緑と赤だけで区別しない）や、
  モノクロの「蛍光管ディスプレイ」風も。
- スクリーンリーダーモード: テキストのみ、枠線なし。アクセシビリティは、MUD が今も
  遊ばれている大切な理由の 1 つです。
- クライアントのマクロとエイリアス（`alias k kill`）、トリガー（「『お腹が空いた』と
  表示されたら『eat bread』を送る」）。
- ログの中の出口や名前をクリックできるように。
- 音: `sound` フレームの効果音を鳴らすシンプルなサウンドエンジン（例: `rodio`）。
- タイル: キー 1 つで切り替えられる複数のタイルセット。チャレンジとして「アイソメトリック」表示も。

## コース

- **バグ探しのレッスン:** コースツールがバグ（データ競合、デッドロック、漏れる
  ゴルーチン）を *仕込み*、`-race`、`pprof`、ログで見つけるレッスン。
- **リファクタリングのレッスン:** 「ミューテックスをアクターに置き換える」（フェーズ 3）は
  その 1 つ。テストは変わらず、コードだけが変わる。
- **本物のコードを読む:** `net/http`、`bufio`、`ratatui` などを使う場面で、その
  ソースコードを短く案内する。
- **ペアプログラミング:** 1 人がサーバー、もう 1 人がクライアントを作り、共有するのは
  プロトコルの文書だけ。フェーズごとに役割を交代する。
- **コードレビュー:** お互いの解答をレビューするためのチェックリスト。
- **カタ:** 概念をもっと練習したい人向けの、言語ごとの小さな独立した演習
  （例:「`ParseCommand` を Rust で実装する」）。
- **コースツールの Web 版:** レッスンとテスト結果をブラウザで表示する（Go: `net/http` +
  `html/template`）。例えば GitHub Codespaces でインストールなしに動かせる。
- **達成バッジ:** 終えたチャレンジを `mudschool list` に表示する。
- **プレイヤーごとのサーバーのメッセージ:** レッスン 38 は世界を訳しました。次は
  プレイヤーごとの `messages`。グローバル定数では足りなくなったときの設計し直しの
  よい練習です。
- **さらに多くの言語:** 同じプロトコルを使えば、クライアントを 3 つ目の言語で書く
  トラックを簡単に追加できます。コース自体も、英語・スウェーデン語・日本語と同じ
  方法でさらに多くの言語に翻訳できます。
