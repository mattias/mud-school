# レッスン 27 – 経路探索

暗い森の狼は、レッスン 16 からあてもなくさまよってきました。これからは **狩り** をします。
あなたを見つけると、角を回り、木をよけ、最短の道でやって来ます。そして深手を負った
ネズミは **逃げ出します**。

```
###############        ###############        ###############
#.............#        #.............#        #.............#
.@.....w......#   ->   .@.w..........#   ->   .@w...........#   「狼が襲いかかってきた！」
#.............#        #.............#        #.............#
```

## 目標

- ゲームで最もよく使われる経路探索アルゴリズム **A\*** を実装する。
- `comparable` で制約した型パラメーターを持つ **ジェネリック** な関数を書く。
- インターフェースを通じて `container/heap`（優先度付きキュー）を使う。
- ローグライク AI の万能ナイフ、**ダイクストラマップ** を学ぶ。

## Go の概念

### `container/heap`

標準ライブラリには出来合いの優先度付きキューはありません。代わりに、`heap.Interface` を
実装すれば *自分の* スライスを優先度付きキューにしてくれるパッケージがあります:

```go
type queue[N any] struct{ items []*entry[N] }
func (q *queue[N]) Len() int           { return len(q.items) }
func (q *queue[N]) Less(i, j int) bool { return q.items[i].f < q.items[j].f }
func (q *queue[N]) Swap(i, j int)      { ... }
func (q *queue[N]) Push(x any)         { ... }  // heap.Push から呼ばれる
func (q *queue[N]) Pop() any           { ... }  // heap.Pop から呼ばれる: 最後の要素を取り除く
```

あとは `heap.Push(q, e)` と `heap.Pop(q)` が、最小の `f` を O(log n) で先頭に保ちます。
注意: 呼ぶのは `q.Push` ではなく `heap.Push` です。

### `comparable` を使ったジェネリクス

```go
func AStar[N comparable](start, goal N, neighbors func(N) []N,
	cost func(a, b N) int, h func(N) int) ([]N, bool)
```

`N` は `==` で比較でき、マップのキーにできるものなら何でもかまいません。ゾーンの `Pos`、
部屋 ID の `string`、テストの `int`。同じ A* がゾーンでも世界のグラフでも経路を見つけます。

## アルゴリズム

### A\*

最も有望なノード、つまり `f = g + h` が最小のノードから調べます。`g` はここまでのコスト、
`h` は残りの *見積もり* です。8 方向の移動がすべてコスト 1 なら、完璧な見積もりは
**チェビシェフ距離** `max(|dx|, |dy|)` です。決して過大に見積もらないので、見つかる経路は
最短です。

```
open := start を入れた優先度付きキュー
キューが空でない間:
	cur := f が最小のノード
	cur == goal なら: came[...] をたどって戻る。それが経路
	各隣接ノード n について:
		g := ここまでのコスト + cost(cur, n)
		n が新しいか g が以前より安いなら: g と came[n] = cur を記録して n を入れる
```

### ダイクストラマップ

**すべての目標から同時に** 幅優先探索をすると、各マスに最寄りの目標までの距離が付きます。
すると判断は簡単です:

- 目標へ向かう: 数値が *最も小さい* 隣へ。
- 離れる: 数値が *最も大きい* 隣へ。

*Brogue* はほとんどすべての怪物の振る舞いにダイクストラマップを使っています。

## 契約

- `AStar[N comparable](start, goal, neighbors, cost, h) ([]N, bool)` – 最も安い経路。
  `start` は **含まず**、`goal` は **含む**。start が goal なら `nil, true`、経路がなければ
  `nil, false`。
- `(z *Zone) Path(from, to Pos, blocked func(Pos) bool) ([]Pos, bool)` – ゾーン内で、8 方向、
  コスト 1、歩けるタイルだけ、`blocked` のマス（`nil` でもよい）は通らない。ただし `to` は除く。
- `DijkstraMap(z, goals []Pos) map[Pos]int` – 到達できる歩けるマスごとに、最寄りの目標までの
  歩数（8 方向）。
- NPC ファイルに新しい振る舞い（`BehaviorSpec` に `range` と `below`）:
  - `{"type": "hunt", "range": 5, "chance": 0.3}` – `ComputeFOV(ゾーン, 自分の位置, range)`
    でプレイヤーを見る（既定の range は 6）。プレイヤーの隣（チェビシェフ距離 ≤ 1）なら攻撃:
    `prey.target = n`、獲物に `MsgAttacksYou`、部屋に `MsgAttacks`。そうでなければ、他の
    生き物を通らずに、最も近い見えるプレイヤーへの `Path` の最初の 1 歩を進む。`chance` =
    ティックごとに行動する確率（0 = 毎ティック）。
  - `{"type": "flee", "below": 0.4}` – 体力が `below` × 最大値を下回り、部屋にプレイヤーが
    いれば: 今いる場所より `DijkstraMap` の値が大きい隣へ進む。
- 既定の世界: 狼は狩り、ネズミは逃げる。
